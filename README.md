# claude_animation

Claude Code CLI 用のデスクトップ常駐ペットウィジェット。Claude Codeが応答を生成している間は「考え中」アニメーション、応答が完了すると「笑顔」になる、画面右下に常駐する小さなキャラクターを表示する。

## 背景

OpenAI Codex CLIには公式のペット機能（`/pet`）があり、エージェントの状態（実行中/入力待ち/レビュー待ち）をキャラクターのアニメーションで可視化している。Claude Codeには同等の公式機能が存在しない（`/buddy` という機能が話題になったことがあるが、実在は確認できていない）。同様の体験を自作する。

## 決定事項（2026-09-16時点）

### 技術スタック
- **Electron** を採用（Mac以外への展開余地を残すため、Swift/AppKitではなくクロスプラットフォームを優先）
- 将来的な軽量化オプションとして Tauri も検討したが、まずはエコシステムが成熟しているElectronで実装する

### 表示仕様
- 画面右下に常時表示（常時最前面ウィンドウ、枠なし・背景透過）
- Claude Code CLIが起動しているときだけ表示する
- Codex CLIのペットが表示されている場合はその隣に配置する
  - Codexのペットはターミナル内に描画されている可能性が高く、OSウィンドウとして位置を取得できない場合がある。実装時に調査し、取得できない場合は画面右下固定 + 大まかなオフセットで近似する

### 状態検知の仕組み（案）
- Claude Codeの hooks機能を使用する
  - `UserPromptSubmit` フック → 状態ファイルに「thinking」を書き込む
  - `Stop` フック → 状態ファイルに「smile（完了）」を書き込む
- Electron側は状態ファイルをポーリングまたは監視し、アニメーションを切り替える
- Claude Code CLIプロセスの有無を監視し、ウィジェットの表示/非表示を切り替える
